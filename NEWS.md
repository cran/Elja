# Elja 1.0.1

* Examples and vignette now use the `SynthDiabetes` data set from
  mlbench (>= 2.1-11), following the removal of `PimaIndiansDiabetes`
  from that package at the request of the NIDDK. Results are similar
  but not identical, the new data being synthetic.
* `mlbench (>= 2.1-11)` is now required in `Suggests`.
